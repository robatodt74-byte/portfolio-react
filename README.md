# Business Card Atlas

名刺をスキャンして保存し、一覧ダッシュボードと関係マップで管理するWeb MVPです。

```bash
npm install
npm run dev
```

## Features

- 名刺の取り込みとローカル保存
- タグと会社キーワードによる分類
- Obsidian風の関係グラフ
- 将来の紹介候補を考えるマッチング下地
